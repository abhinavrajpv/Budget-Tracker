📱 Android Phone Setup & Deployment

100% Safe & Private

Your tasks are stored only on your own device's internal storage. There is no external database or server tracking you.

How to use this on your Android Phone:

1
Option A: Netlify Drop (Easiest — 30 seconds)

Go to app.netlify.com/drop in your browser and drag & drop this project folder. It gives you a free, permanent, secure https://... URL instantly!

2
Option B: GitHub Pages (Free forever)

Push this folder to a GitHub repository, go to Settings > Pages, and turn on GitHub Pages. You get a secure https://yourname.github.io/todo link.

3
Install as an App on Android:

Open the link in Chrome on your phone, tap the three dots (⋮) at the top right, and choose "Install app" or "Add to Home screen". It will open like a native app without browser bars!
