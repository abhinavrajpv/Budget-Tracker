# 🛡️ VaultBudget

A clean, 100% private, zero-knowledge budget and expense tracker. All your data stays strictly on your device with **zero server transmission**.

> 🔗 **Live Demo:** Find the live link in the **About** section of this repository (or open GitHub Pages).

---

## ✨ Features

- **Dynamic Categories on the Fly**: No predefined categories. Create categories as you add transactions, and easily re-use existing ones with auto-complete.
- **Net Amount Left**: Automatically updates and displays your net balance (`Income − Expenses`) with every transaction.
- **Optional Spending Limits**: Set monthly spending limits for any category if you want to. Get instant alerts before you exceed your budget.
- **Visual Analytics**: Interactive category breakdown donut charts and monthly comparison bars (pure HTML5 Canvas, 100% offline).
- **100% Safe & Private**: No cloud database, no external servers, no tracking. Hackers have zero access to your data.
- **Export & Backup**: Export your full ledger to JSON or CSV anytime with one click.
- **Optional Master PIN**: Lock your screen with a 4-digit PIN for extra privacy.

## 📱 How to Use & Install

### 1. In Your Browser
Open the live link directly in any modern browser (Chrome, Safari, Firefox, Edge) on your phone or computer.

### 2. Install as an App (PWA)
VaultBudget can be installed as a standalone app without needing the app store:

- **On Android (Google Chrome):**
  1. Open the live demo link.
  2. Tap the three dots (**⋮**) in the top-right corner.
  3. Tap **"Install app"** (or **"Add to Home screen"**).
  4. VaultBudget will appear on your phone's home screen and app drawer, working **100% offline**.

- **On Desktop:**
  - Click the install icon in your browser's address bar to install it as a desktop app.
